# Matrix Filling Game in C

A console-based matrix filling game developed in the C programming language.

The project includes manual and automatic game modes, score tracking, undo functionality, random matrix generation, and file-based matrix loading.

## Features

- Manual game mode
- Automatic game mode
- Random matrix generation
- Matrix loading from a file
- Score tracking
- Undo functionality
- Console-based menu system

## Technologies Used

- C Programming Language
- Standard C Libraries
- File Handling
- Structures
- Two-Dimensional Arrays
